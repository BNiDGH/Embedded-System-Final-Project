# web_dashboard/ — dashboard สำหรับผู้ใช้

หน้าเว็บแสดงข้อมูลจาก cloud และปุ่มหยุดฉุกเฉิน
เซิร์ฟเวอร์นี้ทำหน้าที่เสิร์ฟไฟล์ static และ proxy ไปยัง cloud/AI
(เบราว์เซอร์จึงไม่ต้องรู้ IP ของอุปกรณ์ในวง LAN)

## รัน

```bash
cp .env.example .env
pip install -r requirements.txt
uvicorn server:app --host 0.0.0.0 --port 8080
```

เปิด <http://127.0.0.1:8080>

## ค่าที่ตั้งได้

| ตัวแปร | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `CLOUD_URL` | `http://127.0.0.1:8000` | cloud API |
| `AI_URL` | `http://127.0.0.1:8001` | ใช้อ่าน `/health` มาแสดงว่าใช้โมเดลอะไร |
| `DASHBOARD_TIMEOUT_S` | `5` | เวลารอ cloud ต่อคำขอ |
| `INGEST_TOKEN` | ว่าง | แนบ `X-Auth-Token` เวลาเรียก `/api/reset` |

## หน้าจอ

- **เส้นทางข้อมูล** — node → gateway → cloud → dashboard รอบล่าสุด
- **เซนเซอร์บนบอร์ด** — ค่าล่าสุดและสถานะออนไลน์ของแต่ละบอร์ด
- **Gateway** — ระยะ HC-SR04, พัดลม, มุม servo, สถานะ E-stop และผล AI
- **แถวดิบใน cloud** — 15 แถวล่าสุด
- **เหตุการณ์** — การตัดสินใจพัดลม/AI/E-stop พร้อมสถานะ Discord
- **เสื้อผ้าที่ AI จำแนกได้** — ยอดนับครั้งที่หยิบ

หน้าดึง `/api/state` ทุก 2 วินาที ถ้า cloud ล่มจะขึ้นแถบสีแดงโดยไม่ค้าง
